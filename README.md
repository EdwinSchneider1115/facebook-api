# Facebook API - Taller Backend

API REST desarrollada con Laravel para simular algunas funciones básicas
de una red social.

## Funcionalidades

- Crear publicaciones.
- Subir múltiples imágenes.
- Listar publicaciones.
- Consultar una publicación.
- Agregar comentarios.
- Dar Me gusta.
- Eliminar publicaciones.
- Eliminar imágenes asociadas.

## Tecnologías

- Laravel
- PHP
- SQLite
- Eloquent
- Postman
